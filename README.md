# 🤖 Nova Chatbot

Nova Chatbot is an AI-powered conversational chatbot designed to provide useful and relevant answers based on the questions asked by the user.

The project provides a simple and interactive chat interface where users can enter questions and receive AI-generated responses.

## ✨ Features

* 💬 Interactive chatbot interface
* 🤖 AI-powered question answering
* ⚡ Fast and responsive UI
* 📝 Chat input and message display
* 🗂️ Chat history support
* 📱 Responsive design
* 🔐 Supabase integration
* 🌐 Modern React + TypeScript architecture

## 🛠️ Technologies Used

* **React** – Frontend development
* **TypeScript** – Type-safe programming
* **Vite** – Development and build tool
* **Tailwind CSS** – Styling and responsive design
* **Supabase** – Backend/database services
* **JavaScript/TypeScript** – Application logic
* **Git & GitHub** – Version control

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/ramasudha428-code/nova_chatbot.git
```

### 2. Open the project

```bash
cd nova_chatbot
cd project
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run on a local development URL such as:

```text
http://localhost:5173
```

Open the URL in your browser.

## 💡 How Nova Chatbot Works

```text
User
  ↓
Enter Question
  ↓
Nova Chatbot
  ↓
Process User Query
  ↓
AI Response
  ↓
Display Answer
```

The user enters a question in the chatbot interface. The application processes the request and generates a relevant response, which is then displayed in the conversation.
